# Repaso de SQL: ventas de tecnología

Usé datos ficticios de ventas para ordenar productos por nombre, filtrar ventas de Colombia, detectar categorías faltantes y calcular los ingresos por categoría.

Abre `ventas_tecnologia.sql` en el Query Tool de pgAdmin y ejecútalo con **F5**. El script también funciona en SQLite. La tabla es temporal, así que ejecuta las consultas en la misma sesión donde la creaste.
